Sistema de Cadastro de Alunos

Projeto em Python para gerenciar alunos com opções de cadastro, consulta, edição e exclusão.

Como executar
1. Clone o repositório:
   ```bash
   git clone https://github.com/Lightis4/sistema-cadastro-alunos.git

2. Entre na Pasta
cd sistema-cadastro-alunos

3. Execute
python main.py

Estrutura :

main.py → menu principal
cadastro.py → cadastrar aluno
consulta.py → consultar alunos
editar.py → editar aluno
excluir.py → excluir aluno
